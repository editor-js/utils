UI Kit Preview

Every popover the package exports. The mobile popover only gets its bottom-sheet look below 650px of viewport width, so narrow the window to see it as it is on a phone.

Desktop — every item type

Searchable menu with icons, secondary labels, a radio group, a toggle, a disabled item, a hint, a confirmation, a separator, custom HTML and overridden item semantics.

Desktop — plain menu

No search, no icons, items close the popover on activation. Keyboard navigation is disabled with flippable: false.

Desktop — nested popover

Nested items open as a separate popover on hover. Children are rendered with their own params: no search here, plus an onOpen handler that focuses a custom input.

Desktop — translated messages

All the texts the popover renders or announces are overridden via messages. Search for something missing to see the "nothing found" message.

Inline — toolbar

Horizontal bar of toggle buttons. The second item has no title and gets its accessible name from the hint instead.

Inline — with nested popover

The "Link" item has children opened right away via isOpen, the way the link tool shows the URL input. Clicking the item toggles the nested popover.

Inline — over a selection

What the inline popover is made for: select the text below and the toolbar appears near the selection, keeping it intact.

Select any part of this text to see the inline popover.

Mobile — bottom sheet

Modal dialog pinned to the bottom of the screen. Nested items replace the current ones and get a header with the back button. Narrow the window below 650px to see the real layout.
